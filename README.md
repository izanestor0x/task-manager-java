# Task Manager (Java)

A command-line application to manage a to-do list. Learning project for Java and OOP.

## Features
- Add a task
- List tasks
- Mark a task as completed
- Delete a task

## Requirements
- Java 21 (or the version you use)
- Maven

## How to run
    git clone https://github.com/izanestor0x/gestor-tareas-java
    cd gestor-tareas-java
    mvn compile exec:java
